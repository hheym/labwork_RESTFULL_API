# Task Manager RESTfull API сервис

Лабораторная работа по созданию RESTfull API сервиса на Python.

## Описание

Реализован упрощённый Task Manager, в котором есть две связанные модели:

- `Project` — проект;
- `Task` — задача, относящаяся к определённому проекту.

Один проект может содержать несколько задач.

## Модель Project

Поля:

- `id` — уникальный идентификатор;
- `name` — название проекта;
- `description` — описание проекта;
- `deadline` — дедлайн;
- `status` — статус проекта: `planning`, `in_work`, `done`.

## Модель Task

Поля:

- `id` — уникальный идентификатор;
- `title` — название задачи;
- `description` — описание задачи;
- `status` — статус задачи: `planning`, `in_work`, `done`;
- `project_id` — идентификатор проекта, к которому относится задача.

`project_id` является внешним ключом на `projects.id`.

При удалении проекта связанные с ним задачи удаляются автоматически (`ON DELETE CASCADE`).

## Реализованные методы

### Projects

- `GET /api/projects` — получить список проектов;
- `GET /api/projects/{id}` — получить проект по id;
- `POST /api/projects` — создать проект;
- `PATCH /api/projects/{id}` — изменить проект;
- `DELETE /api/projects/{id}` — удалить проект.

### Tasks

- `GET /api/tasks` — получить список задач;
- `GET /api/tasks/{id}` — получить задачу по id;
- `POST /api/tasks` — создать задачу;
- `PATCH /api/tasks/{id}` — изменить задачу;
- `DELETE /api/tasks/{id}` — удалить задачу.

## Коды ответов

- `200 OK` — успешный GET, POST или PATCH;
- `202 Accepted` — успешное удаление;
- `400 Bad Request` — ошибка валидации входных данных;
- `404 Not Found` — объект не найден;
- `500 Internal Server Error` — внутренняя ошибка сервера.

## Валидация

Проверяются:

- обязательные поля;
- максимальная длина строк;
- корректность даты;
- допустимые значения статуса;
- существование проекта при создании задачи.

## Тесты

Для проверки API используются автоматические тесты на `pytest`.

Тестами проверяются:

- CRUD для `Project`;
- CRUD для `Task`;
- ошибки `400`;
- ошибки `404`;
- код `202` при удалении;
- создание задачи только для существующего проекта;
- каскадное удаление задач при удалении проекта.
